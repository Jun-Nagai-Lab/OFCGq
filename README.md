# OFCGq
This contains code for analyzing raw fiber photometry, RNA-sequencing, and TissueCyte whole-brain images.

Fiber photometry:
Includes code for downsampling and analysis of z-scored traces, including peak to late values and AUC.
Python ver. 3.13.1 

RNA-sequencing:
Contains batch scripts for raw FASTQ file processing and differential gene expression analysis in R using edgeR.
R ver. 4.5.3
RStudio ver. 2026.07.1
Batch scripts

Whole Brain Analysis:
Includes R code used to analyze regional intensity values extracted from NeuroInfo.
R ver. 4.5.3
RStudio ver.2026.07.1
